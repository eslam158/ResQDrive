# ResQDrive

**Offline AI-Based Accident Detection Mobile Application**

ResQDrive is a mobile application designed to detect potential road accidents using on-device machine learning and smartphone sensors.

## Key Features
- Offline accident detection
- Sensor data analysis
- Crash, near-miss, and normal-driving classification
- Flutter mobile application
- On-device AI inference

## Technologies
- Flutter & Dart
- Python & TensorFlow
- Machine Learning
- Accelerometer and Gyroscope
- GPS
